**Meetingmonger** — one word for the boss. A boss who deals in meetings the way a fishmonger deals in fish: one more sync, one more stand-up, one more "quick call" that eats the afternoon. `main.ts` scores a shortlist of candidate words against the judge's brief (funny on its own, rings true, fresh, travels), picks the winner deterministically, validates it against the 1–30 character gate, and writes exactly that word to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-word-for-the-boss node main.ts
```
